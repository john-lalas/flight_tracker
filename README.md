# flight_tracker
## Motivation
Some projects are valuable because they create curiosity.

A live flight tracker is one of those projects.

The idea:

Display airplanes currently flying around the world on a map.

Users can see:

- Aircraft location
- Flight number
- Airline
- Destination
- Speed
- Altitude

At first, it sounds simple.

But behind the scenes, you are working with interesting engineering problems.

You need:

- External APIs
- Real-time updates
- Maps
- Location data
- Data processing

You learn concepts like:

- Geospatial information
- WebSockets
- Live data synchronization
- Map rendering

The exciting moment is when you look at the map and realize:

“That airplane above my house is actually the same plane shown on my screen.”

Projects like this remind you why programming is fun.

You are not only writing code.

You are connecting digital information with the real world.
